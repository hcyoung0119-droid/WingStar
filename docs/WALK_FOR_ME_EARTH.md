# WALK FOR ME → WALK FOR EARTH

앱의 중심은 걷기 명상이다. 기존 걷기 측정, 호흡 명상, 마음 기록·달력, 개인 플로깅, ESG, 미션, 윙코인, 샵, 마이 기능을 유지하며 하나의 흐름으로 연결했다.

## 평소의 사용 흐름

홈의 '오늘의 걷기 명상' → 5/10/20분 코스 선택 → 음악 선택 → 시작. 기존 걸음 센서와 선택한 GPS 거리 기록을 사용한다. 코스별 시간·걸음·거리를 기록 탭에서 확인한다. 잠시 화면을 벗어났다면 '이어서 걷기'로 진행한다.

타이머는 단조 시계를 기준으로 계산하며 정지 구간을 제외한다. 완료는 목표 시간을 충족했을 때만 기록하고 중도 종료와 구분한다. 페이지 이동 중에는 코스 상태를 유지한다. 웹앱의 화면 숨김·잠금 시 코스와 음악을 멈추며, 다시 보일 때 자동으로 재생하지 않는다. 지원 브라우저에서는 화면 깨우기 기능을 요청한다. 아이폰의 실제 잠금·전화 인터럽트·센서·개인 파일 형식별 재생은 실기기 검증이 아직 필요하다. 앱이나 브라우저를 완전히 종료한 코스는 자동 완료로 복원하지 않는다.

## 음악과 출처

- 기본 '고요한 발걸음': WingStar 프로젝트가 이 앱을 위해 새로 작성한 Web Audio 합성 사운드. 외부 곡, 기존 멜로디, 녹음 샘플을 사용하지 않았다. 낮은 사인파 화음을 긴 페이드로 연결한다.
- 출처는 음악 선택 영역과 '음악·음성 출처 보기', 공개 `/music-credits.html`에 표시한다.
- 한국어 음성 안내는 앱의 안내 문장을 기기 음성 합성으로 읽는 선택 기능이다. 기기별 음성 지원은 다르다.
- 개인 음악: 사용자가 파일 선택창에서 고른 파일만 읽는다. MP3/M4A 권장, 최대 50MB. 해당 브라우저의 IndexedDB에 보관하고 서버로 업로드하거나 공유하지 않는다. 저장할 수 없으면 이번 실행 중에만 사용하는 상태를 알린다. 음악 선택·삭제·음량·미리 듣기·끄기를 지원한다. 파일별 권리는 기본 사운드와 별개이다.
- 기기 음악 기능은 현재 아이폰/웹 배포에 연결했다. Windows/Android 네이티브 배포에 오디오 플러그인은 아직 추가하지 않았다.

## 재접속과 권한

GPS 기록 여부·센서 민감도·음성 안내는 변경 즉시 기기 설정에 저장한다. 음악 선택·음량·켜짐도 별도 로컬 설정으로 복원한다. 저장된 개인 음악은 파일 선택창을 다시 열지 않아도 재생할 수 있다. 화면을 벗어날 때 미저장 기기 기록을 한 번 더 저장하며, 재접속 자체로 센서나 음악을 켜지는 않는다.

동작 권한은 현재 문서에서 실제 허용된 결과를 재사용하고 진행 중인 요청을 합친다. 재접속 때 이전 허용 이력이 있으면 짧게 실제 센서 이벤트를 확인한다. 브라우저가 전달한 센서 신호를 확인한 경우에만 허용 상태를 재사용하며, 로컬 저장값만으로 권한을 허용 처리하지 않는다. 신호가 없으면 걷기 시작 버튼의 사용자 동작 안에서 권한을 요청한다. 센서 보정 실패 시 재확인할 수 있다.

웹 GPS는 `watchPosition` 한 번으로 브라우저의 현재 권한을 사용하거나 필요한 허용을 요청한다. 기존 `requestPermission`의 단발 위치 조회와 뒤이은 감시가 중복되던 경로를 제거했다. 네이티브 권한 처리는 유지한다. Safari/iOS가 동작 권한을 초기화하거나 사용자가 일회성 위치 허용을 선택하면 앱 코드가 이를 영구 허용으로 바꿀 수 없다. 마이 탭의 접힌 안내에 WingStar 사이트만 위치를 허용하는 설정 경로를 제공한다. Safari·홈 화면 웹앱·카카오톡의 저장소·권한은 서로 다를 수 있다.

권한 참고: [Apple의 웹사이트별 위치 설정 안내](https://support.apple.com/en-ca/guide/iphone/iphb01fc3c85/ios), [DeviceMotion 사용자 동작 요구](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static).

## GREEN WALK 준비 상태

운영진과 운영 기간이 미정이라는 사용자의 답변에 따라 캠페인 접수는 열지 않았다. '지구를 걷는 마음' 20분 코스를 미리 체험할 수 있다. 코스 단계는 0–5분 발의 감각, 5–10분 주변 알아차리기, 10–15분 잠시 멈춰 환경 돌보기, 15–20분 감사와 마무리다.

예정 조건: 걷기 명상 20분, GPS 1km, 쓰레기 5개, 활동 후 사진 1장과 운영진 확인. 앱이 사진이나 쓰레기 수를 자동 인증한다고 표시하지 않는다. 현재 사진 접수·승인·Green Point 지급·굿즈 주문은 비활성이다. 기존 개인 플로깅 기록은 계속 사용할 수 있다.

RE:WARD는 기존 샵에 캠페인용 안내로 연결했다. 예정 누적 포인트 1/3/5/10회 = 100/300/600/1,500P, 폐현수막 필통 1,000P, 폐청바지 파우치 1,500P를 표시한다. 이는 현재 획득 가능한 잔액이 아니며 보상 단가·물류 확정 전의 기획안이다. Green Point는 윙코인과 별개이며 전환·차감하지 않는다.

운영을 시작할 때 필요한 작업: 운영 기간·담당자·심사 기준 확정, 계정과 서버 제출 DB, 비공개 사진 저장소 및 보관/삭제 정책, 승인·반려 화면, 중복 제출·중복 지급 제어, Green Point 서버 원장, 실제 상품 공급·배송 연결. 사진만으로 5개를 주웠다는 사실을 자동 확정하지 않는다. 검증·운영 전에 로컬 데이터로 실물 리워드를 지급하지 않는다.
