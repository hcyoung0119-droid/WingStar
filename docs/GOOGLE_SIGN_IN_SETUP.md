## 소유자가 한 번 설정할 내용

1. [Google Cloud Console](https://console.cloud.google.com/)에서 WingStar용 프로젝트를 선택하거나 만듭니다.
2. **Google Auth Platform → Branding / Audience**에서 앱 이름, 연락용 이메일 등 실제 정보를 입력합니다. 외부 사용자용으로 설정합니다. 테스트 상태라면 테스트 사용자만 로그인할 수 있으므로 공개 서비스 전에는 게시 상태와 Google이 요구하는 확인 항목을 완료합니다. 운영 주체·지원 연락처는 실제 정해진 정보만 사용합니다.
3. **Clients → Create client → Web application(웹 애플리케이션)**을 선택합니다.
4. **Authorized JavaScript origins(승인된 자바스크립트 원본)**에 아래 주소를 정확히 추가합니다. 경로와 마지막 `/`는 넣지 않습니다.

   `https://wingstar-care.use-loing-ai.chatgpt.site`

5. 생성된 **Client ID**(`…apps.googleusercontent.com`)를 앱에 등록합니다. Client secret은 이 로그인 방식에 필요 없습니다.

현재 구현은 Google Identity Services의 팝업 버튼 + JavaScript callback 방식입니다. 별도 OAuth redirect URI는 사용하지 않습니다. 로그인 페이지는 `/account/sign-in`이며, 인증을 마치면 앱의 랭킹으로 돌아갑니다. Google에서 출처 등록·게시를 제한하면 해당 제한을 먼저 해결해야 합니다. 다른 도메인을 추가하면 앱의 신뢰할 원본 설정도 함께 변경해야 합니다.

## 연결 시 처리할 내용

- 전달받은 공개 ID를 Sites 런타임 환경 변수 `GOOGLE_CLIENT_ID`로 등록합니다. 비밀키는 등록하지 않습니다.
- Google이 일반 공개 상태로 전환된 것이 확인되면 `GOOGLE_AUTH_STAGE=production`을 등록하고 배포하여 테스트 안내를 해제합니다. 실제 Google 상태와 다르게 바꾸면 안 됩니다.
- `/privacy`에는 현재 수집·저장·공개 범위를 설명하는 테스트 서비스 안내가 있습니다. 운영진은 미정이며, 문의 이메일은 사용자가 공개용으로 지정한 뒤 `PUBLIC_SUPPORT_EMAIL`에 등록합니다. 계정 삭제·보유기간 등 남은 준비가 완료되어야 정식 정책으로 확정할 수 있습니다.
- 최신 서버를 배포한 뒤 실제 소유자 계정으로 로그인하고, 서로 다른 두 계정으로 요청·수락·주간 랭킹을 확인합니다. 현재 자동 검증은 테스트 키를 사용하며 실제 Google 로그인 성공을 의미하지 않습니다.
- iPhone의 카카오톡 내장 브라우저에서 Google 로그인이 제한되면 Safari로 같은 링크를 열어 로그인합니다. 로그인은 브라우저별로 유지되며, 브라우저를 바꾸면 다시 로그인할 수 있습니다.

## 저장·공개 범위

- 서버: Google 계정의 고정 식별자에 대응하는 WingStar 아이디, 별도 공개 닉네임·배경색·장식, 친구 관계, 로그인 후 업로드한 걸음 기록, 응원. Google 이메일·프로필 사진은 저장하지 않습니다.
- 고유 아이디는 같은 Google 계정이면 다른 휴대폰에서도 같습니다. 친구는 상대가 요청을 수락해야 연결됩니다.
- 친구 검색은 공개 닉네임의 부분 검색이 기본입니다. 1~24자, 한 번에 최대 20명이며 같은 닉네임은 구분용 아이디와 배경색·장식으로 확인합니다. 전체 고유 아이디로 정확히 검색하는 기능도 유지합니다. 검색은 로그인한 사용자에게만 제공하며 메일·개인 사진·마음 기록은 검색 결과에 포함하지 않습니다.
- 친구 랭킹은 수락한 친구끼리 표시합니다. 전체 랭킹 참여는 기본 꺼짐이며 사용자가 직접 켭니다. 기준은 한국 시간 월요일 00시부터의 주간 걸음입니다.
- 마음 기록, 개인 프로필 사진·소개, 개인 음악 파일은 기기에 남으며 계정별 저장 영역을 사용합니다. 최초 로그인 계정은 기존 기기 기록을 이어받습니다. 이 개인 자료는 새 휴대폰에 자동 복원되지 않습니다.
- 임시 전송 대기 걸음은 해당 계정의 기기에 최대 7일 보관하며, 재전송해도 중복 합산하지 않습니다. 테스트 걸음과 기존 데모 기록은 업로드하지 않습니다.
- 걸음 랭킹은 기기가 보내는 활동을 기반으로 합니다. 부정 참여 방지 인증이나 금전·상품 리워드 지급 근거가 아닙니다. 기존 결제·캠페인 준비 상태는 그대로 유지합니다.
- 로그인 세션은 최대 30일이며 서버에서 만료·로그아웃을 확인합니다. 쿠키 삭제나 브라우저 설정에 따라 더 일찍 로그아웃될 수 있습니다.
