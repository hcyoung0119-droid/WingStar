# WingStar 결제 연결 상태

사용자 확정 가격: Premium 월 4,900원, Membership+ 월 9,900원.
현재 PG 미가입. 실제 청구, 자동 갱신, 유료 회원 권한 부여는 비활성 상태다.

## 이번 변경

- 기존 디자인의 멤버십 화면에 두 월 요금과 출시 준비 상태를 표시한다.
- 버튼만으로 유료 회원과 XP를 얻던 데모 동작을 제거했다.
- localStorage에 저장된 과거 유료 회원 표시와 데모 쿠폰을 복원하지 않는다.
- 상품 공급사와 연결되지 않은 쿠폰 발급/코인 차감을 중지했다.
- `server/payments/toss.mjs`는 서버용 토스페이먼츠 API 어댑터다. 빌링키 발급, 승인, 조회, 전액 취소, 키 삭제를 지원한다. 금액은 서버 상품표로 결정하고 승인 결과의 주문·금액·통화·상점을 검증한다. 네트워크 결과 불명과 승인 거절을 구분한다.
- 어댑터는 현재 정적 사이트에 배포되거나 앱 버튼에 연결되지 않았다. 단위 테스트는 대체 응답을 사용한다. 실제 PG 테스트/라이브 결제 검증은 아직 하지 않았다.

## 운영 연결에 필요한 작업

1. 사업자/정산 주체로 PG에 가입하고 월 정기결제(빌링) 계약을 신청한다. 토스페이먼츠 기준으로 준비했으며 계약은 사용자가 진행한다.
2. 실제 서비스할 유료 혜택, 판매자 정보, 문의처, 이용약관·개인정보 처리·해지·환불 조건을 확정한다. 기존 AI 코칭은 예시 데이터이므로 실제 유료 AI 서비스 연결도 필요하다.
3. 구매자 로그인 및 계정 복구, 서버 주문/구독/결제 DB를 구현한다. 공개 앱 열람은 로그인 없이 유지하되 구매와 유료 권한은 인증 계정에 귀속해야 한다.
4. 서버에 테스트 클라이언트 키·시크릿 키·MID를 보안 설정으로 넣고 SDK 카드 등록 → 서버 빌링키 발급 → 서버 승인 → DB 저장 → 앱 권한 반영을 연결한다. 비밀키와 빌링키를 웹 번들, 로컬스토리지, Git에 넣지 않는다.
5. 주문을 먼저 영구 저장하고 같은 주문의 재시도에는 같은 멱등키를 사용한다. 결과가 불명확하면 주문 조회 후 정합성을 확인한다. URL 성공 콜백이나 웹훅 본문만으로 권한을 부여하지 않는다.
6. 중복 콜백/동시 요청 제어, 월별 갱신 스케줄러, 해지(다음 청구 중지), 실패 재시도 정책, 환불·웹훅 대조, 영수증·결제내역 화면을 연결한다. 빌링키는 서버에서 암호화 보관한다.
7. 테스트 승인·거절·취소·환불·갱신·중복 요청을 검증한 뒤 라이브 키로 전환한다. 키 설정만으로 판매가 완료되는 구조가 아니다.

쿠폰 교환에는 별도 상품 공급사와 실제 발급/취소/정산 연동이 필요하다. 체험용 코인은 현금성 매출이 아니다. 월 예상 구독 총매출은 `4,900 × Premium 유료 인원 + 9,900 × Membership+ 유료 인원`이며 순이익은 결제 수수료, 환불, 세금, AI/서버/리워드 비용 등을 차감해 계산해야 한다. 미확정 비용이나 수익률은 가정하지 않는다.
