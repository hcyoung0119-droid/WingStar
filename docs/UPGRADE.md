# WingStar 업그레이드 통합본

이전 앱의 화면·메뉴를 바탕으로 최신 네이티브 측정 기능을 연결했습니다.

최신 웹앱의 중심은 5·10·20분 걷기 명상입니다. 기존 활동을 유지하면서 GREEN WALK 환경 캠페인과 RE:WARD를 준비 화면으로 연결했습니다. 기본 합성 음악·개인 음악 추가·코스 기록과 운영 준비 범위는 [걷기 명상 연결 안내](WALK_FOR_ME_EARTH.md)를 참고하세요.

- 유지: 하늘색 디자인, 온보딩, 걸음 링, 홈·마인드·기록·샵·마이, ESG·호흡·코칭 화면.
- 업그레이드: 기존 걷기 시작 버튼으로 센서 보정(3~5초), 걸음 감지, 민감도 조절, 측정 시간, 선택적 GPS 거리 기록.
- 걷기 측정 설정을 펼치면 민감도와 GPS 설정이 나옵니다. GPS는 걷기를 시작하기 전에 켭니다.
- Windows에는 휴대폰 가속도 센서가 없어 걷기 시작 후 설정 안의 ‘테스트 흔들림 +1’로 확인합니다. 테스트 걸음은 실제 걸음·미션·보상에 합산하지 않습니다.
- 실제 걸음은 0부터 측정합니다. 이전 데모의 임의 걸음 증가를 실제 센서 이벤트로 교체했습니다.
- 보상 서버·결제·AI 서비스는 연결되지 않았습니다. 샘플 기록·코칭은 데모이며 유료 판매와 상품 교환은 비활성입니다. 웹앱은 아래 안내처럼 기기 저장소에 기록을 보관합니다.

## 홈과 마음 화면 업데이트

- 홈에는 걷기·명상·플로깅·ESG를 같은 크기의 카드로 배치합니다. 단축키는 해당 페이지만 열며 활동을 자동으로 시작하지 않습니다.
- 기존 걸음 링과 센서 설정은 걷기 페이지에서 사용합니다. 명상 페이지에서 1분 호흡을 시작하고, 플로깅 페이지에서는 직접 수거한 쓰레기를 기록합니다. 플로깅 횟수와 수거량은 웹앱의 기기 저장소에 보관하며 ESG 환경 활동에 반영합니다.
- 감정·일기·미소·캘린더 단축키는 마음 탭의 해당 화면을 직접 선택합니다. 활동 미션은 기록 탭에서 이용합니다.
- 마음지수는 마음 탭에만 표시합니다.
- 캘린더는 휴대폰의 로컬 날짜를 사용합니다. 월별 마지막 날(28/29/30/31일), 요일, 오늘 표시, 이전/다음 달, 날짜별 감정과 일기를 지원합니다. 날짜가 바뀌거나 앱으로 돌아오면 오늘 표시를 갱신합니다. 별도의 휴대폰 일정 앱 접근 권한은 필요하지 않습니다.
- 윙코인 환산 기준은 1:1이며 화면에 중복 단위나 환산 설명을 표시하지 않습니다.

## Windows 실행

ZIP 전체를 새 폴더에 풀고 `wingstar.exe`를 실행하세요. 같은 폴더의 DLL과 data 폴더가 필요합니다.
이전 localhost 웹앱, 소스 폴더와 첨부 원본은 수정하지 않았습니다. 이 통합본은 Chrome 서버 없이 실행하는 별도 Windows 배포본입니다.

## Android 휴대폰 전달

`WingStar-Android-0.2.0.apk`를 휴대폰으로 복사한 다음 파일을 열어 설치합니다. 이 파일은 Android용이며 아이폰에서는 설치할 수 없습니다.

공유용 빌드: `flutter build apk --release --build-name=0.2.0 --build-number=2`

이 APK는 로컬 테스트 서명으로 만든 직접 설치용입니다. 앱스토어 공개 배포용 서명은 별도 준비가 필요합니다. 위치 권한은 사용자가 GPS 거리 기록을 켜고 걷기를 시작했을 때 요청합니다.

## 아이폰 Safari 웹앱

멤버십 가격은 Premium 월 4,900원 / Membership+ 월 9,900원입니다. 결제사 미가입으로 현재 유료 판매 및 상품 교환은 준비 중입니다. 과거의 로컬 구독 전환·가상 쿠폰 발급은 제거했습니다. 서버용 결제 어댑터는 준비했지만 아직 앱에 연결되지 않았습니다. 상세 상태는 [결제 연결 안내](PAYMENTS.md)를 참고하세요.

공개 주소: https://wingstar-care.use-loing-ai.chatgpt.site/

Safari에서 링크를 열고 공유 → 홈 화면에 추가 → 웹 앱으로 열기를 선택합니다. 카카오톡 안에서 열었다면 Safari로 열기를 선택하세요.

마이 탭 맨 아래에만 있는 ‘카카오톡으로 공유’는 iOS 공유창을 엽니다. 공유창에서 카카오톡을 선택하세요. 카카오톡이 없거나 브라우저 공유를 지원하지 않으면 앱 링크를 복사해 전달할 수 있습니다. 카카오 SDK 키가 필요한 직접 메시지 발송은 사용하지 않습니다.

개인 기록은 브라우저의 이 기기 저장소에만 저장하며 공유 내용에는 공개 앱 링크만 포함합니다. 저장소를 지우면 기록도 사라집니다. Safari와 홈 화면 웹앱 사이의 저장소 공유는 보장하지 않습니다.

아이폰 동작 권한은 걷기 시작을 눌렀을 때 요청합니다. 측정은 웹앱이 보이는 동안만 가능하며 HealthKit, 건강 앱 누적 걸음, 화면 잠금 중 백그라운드 측정은 지원하지 않습니다. 네이티브 앱의 센서 필터·보정 로직을 재사용합니다. 기기별 정확도와 실제 카카오톡 대상 선택은 아이폰에서 확인이 필요합니다.

검증: Flutter 단위/위젯 검사, 웹 컴파일, JavaScript 브리지 계약 검사. 선택적 WebMCP 읽기 도구는 지원 브라우저에서의 별도 계약 검증을 완료하지 않았습니다.

## 소스 및 검증

이전 UI 원본: C:\Users\hwchy\wing-star\app\lib

통합 소스: C:\Wingstar\lib

최신 측정 엔진: lib/services/step_engine.dart 및 location_engine.dart

`flutter analyze`, `flutter test`로 정적 검사 및 UI·센서 연동 검사를 실행합니다. 실제 모바일 센서와 Windows 위치 권한은 실기기 검증이 필요합니다.

표준 전체 빌드: `flutter create --org com.wingstar --project-name wingstar --platforms=windows .` 후 `flutter build windows --release` (Visual Studio C++ 필요).

현재 PC용 패키지는 최신 Dart AOT/화면 자산과 동일 SDK의 Flutter 런타임을 생성하고, 사용자가 제공한 ZIP의 Windows runner 및 geolocator DLL을 재사용했습니다. 네이티브 플러그인을 추가하면 runner 전체를 다시 빌드해야 합니다.
